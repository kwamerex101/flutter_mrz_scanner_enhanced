# Phase 2 Baseline (pre-optimization)

This file records the baseline numbers captured BEFORE any of the Phase 2
perf changes (Tasks 2-7) land. The benchmark scaffolding (`integration_test/
scan_image_bench_test.dart`) was committed first, by design (Task 1), so the
"before vs. after" delta is provable.

## How to capture

```sh
cd example
flutter pub get
flutter test integration_test/plugin_integration_test.dart --reporter=expanded
# OR (plugin root):
# flutter test integration_test/scan_image_bench_test.dart --reporter=expanded
```

Read the JSON line printed to stdout (key: `== scan_image_bench == { ... }`)
and copy the values into the table below. The same JSON is also written to
`build/bench/scan_image_bench.json` (best-effort).
